# To Her Majesty — A Royal Letter of the Heart

A bespoke, one-of-a-kind romantic website built with pure HTML, CSS & JavaScript.

## 📁 Structure

```
que-royal-letter/
├── index.html      # Main page (all 12 chapters)
├── style.css       # Royal theme — burgundy, gold, ivory
├── script.js       # Petal canvas, scroll reveal, flip cards, video
└── media/
    ├── M1.mp4      # Video — The Funny Truth
    ├── M2.jpeg     # Gallery — Who She Is
    ├── M3.jpeg     # Teacher section
    ├── M4.mp4      # Finale video
    ├── M5.mp4      # Prayer & Gratitude
    ├── M6.jpeg     # Hero portrait (front page)
    ├── M7.jpeg     # Dreams
    └── M8.jpeg     # Places of Peace
```

## 🚀 Deploy to GitHub Pages

1. Create a new GitHub repository (e.g. `royal-letter`)
2. Push this folder's contents to the `main` branch
3. Go to **Settings → Pages → Source: main branch / root**
4. Your live link: `https://<username>.github.io/royal-letter`

## 💫 Features

- Animated falling rose petal canvas
- Morph portrait animation (M6)
- Scroll-reveal on every section
- Flip-card heart questions
- Auto-play videos on scroll
- Royal British typography (Cinzel + Cormorant Garamond + Great Vibes)
- 12 Chapters: Salutation → Finale
- Fully responsive (mobile-first)
